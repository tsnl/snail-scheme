# Ack stack diagnostics, 15 October 2026

The checked SFIR Wasm Ack route remains **failed** with `Maximum call stack size
exceeded`. A private-worker rewrite of that module passes one default V8 probe
while preserving its arithmetic checks. This hand-transformed Wasm is diagnostic
evidence; it supplies no replacement compiler result or clean timing sample.

The [machine-readable summary](20261015-ack-stack.json) records exact identities,
outcomes and command references. The
[compact evidence bundle](https://github.com/tsnl/snail-scheme/blob/16f4423c9f0f579d9cf154c171309755a3d7ae05/benchmarks/sfir/evidence/20261015-ack-stack-diagnostics.tar.gz) retains original
failure records, small input/artifact snapshots, experimental scripts and focused
disassembly excerpts. This report changes no original full57 campaign file.

## What changed in the representation

[PR #234](https://github.com/tsnl/snail-scheme/pull/234), commit
`0df80903cb5c1bddff8c134a576765db8cd271f7`, removed inference's
`infer-application`/`infer-direct-let` shortcut. Every application now follows
`infer-call`, which correctly keeps lambda parameters monomorphic under ordinary
rank-one typing. Restoring inference-time generalization would violate that
contract.

The retained source diff and raw modules explain a consequence for Ack's local
benchmark loop. The historical module makes it a direct function with scalar
captures. The checked module keeps a closure factory and recursive loop closure.
Ack and that loop share `$call27`; the loop needs its environment, so Binaryen
retains the shared type's environment parameter even though Ack never reads its
own parameter. Historical optimized Ack takes only two I64 arguments.

The relevant implementation paths are
[ordinary calls](../../../src/snail-scheme/strict-infer.sld),
[direct-procedure selection](../../../src/snail-scheme/strict-specialize.sld) and
[closure invocation](../../../src/snail-scheme/strict-wasm.sld). This is source and
structure inspection across retained snapshots, not a single-commit bisection.

The nested Ack invocation is still an ordinary `call`; its tail positions retain
`return_call`. Non-tail recursion requires finite stack space. These failures
provide no evidence that proper tail calls were lost.

## Controlled diagnostic variants

The guard-removal variant replaces only Ack's four signed-I64 overflow guards
with no-ops. It preserves the arithmetic and recurrence but still overflows the
default V8 stack. Removing required arithmetic traps is insufficient and cannot
serve as an implementation fix.

The checked-worker variant retains the original closure entry as a wrapper and
moves its complete checked body into a private two-I64 worker. Its script first
asserts that Ack never reads its environment parameter. All three recursive
environment expressions still evaluate as discarded values before the original
call arguments. Arithmetic, all four overflow guards, readiness checks, recursive
calls and results remain intact; ordinary calls and tail calls keep their kinds.

The inverse audit reconstructs the original checked Ack exactly and separately
compares every other original module item for structural equality. Both assertions
passed in the retained command and again during report preparation. The experiment
then uses the existing mandatory Binaryen pipeline, including `-O3`,
`--closed-world`, `--always-inline-max-function-size=40` and `--converge`.

Every listed SFIR execution uses the current frozen scalar host and unchanged
canonical specification: count 2, inputs 3 and 12, result 32765, four workload
barriers and zero setup barriers.

## Why cold frame sizes do not settle the cause

Cold eager compilation reports these explicit `rsp` reservations and safepoint
stack-slot counts for Ack, or for its private worker:

| Artifact | Liftoff reservation | Liftoff slots | TurboFan reservation | TurboFan slots |
| --- | ---: | ---: | ---: | ---: |
| Historical original | 32 B | 11 | 32 B | 8 |
| Checked original | 80 B | 18 | 32 B | 8 |
| Checked private worker | 48 B | 13 | 32 B | 8 |

Reservations are individual instructions, not complete activation sizes. Cold
TurboFan reports the same reservation and slot count for all three artifacts,
yet both forced tiers fail where default adaptive execution can pass. Static
frame size alone therefore does not explain the outcome. Hot compilation,
inlining and live values across non-tail calls remain untraced. The concrete
experiment establishes that calling representation can change this default-route
result while retaining all required checks; it establishes no general stack-depth
guarantee or performance improvement.

environment requirements. Either change needs its own general implementation,
live-root reasoning and execution tests; this experiment validates only Ack's
concrete rewrite.
