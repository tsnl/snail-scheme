# Tutorials

Small complete programs, each run by the repository's test suite with the
output shown. Run one with

```sh
./scripts/lofi-tool run examples/fibonacci.sld
```

- [Fibonacci](fibonacci.md): a typed recursive function and output.
- [Colors](colors.md): structs, enums, typeclasses and pattern matching.
- [Effects](effects.md): effect rows and handlers.
- [Scheme on Lofi](scheme.md): the same kind of program through
  `(scheme base)`.

[Siegework](../../games/siegework.md) is the complete application.
