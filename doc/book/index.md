# Snail-Scheme

Snail-Scheme is a language and application toolkit built around Snail-Core, a
typed functional language with Scheme syntax that compiles to WebAssembly
with garbage collection. The compiler is written in Snail-Core and compiles
itself.

- [Snail-Core](snail-core/index.md): the language, its types,
  libraries, compiler and application model.
- [Tutorials](snail-core/tutorials/index.md): small complete programs to read and
  run. Start here to write something.

As an extra, [Siegework](games/index.md) is a colony game written entirely
in Snail-Core. **[Play it](play/siegework/)** in a browser with WebGPU.

Find the source in the [repository](https://github.com/tsnl/snail-scheme),
and how to install the tools in its
[getting started guide](https://github.com/tsnl/snail-scheme/blob/main/doc/getting-started.md).
The book describes implemented contracts and marks proposals explicitly;
[GitHub issues](https://github.com/tsnl/snail-scheme/issues) track open work.
