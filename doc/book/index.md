# Snail-Scheme

Snail-Scheme is a language and application toolkit built around Lofi, a
typed functional language with Scheme syntax that compiles to WebAssembly
with garbage collection. The compiler is written in Lofi and compiles
itself.

- [LoFI: Low-Level Functional IR](lofi/index.md): the language, its types,
  libraries, compiler and application model.
- [Tutorials](lofi/tutorials/index.md): small complete programs to read and
  run. Start here to write something.

As an extra, [Siegework](games/index.md) is a colony game written entirely
in Lofi. **[Play it](play/siegework/)** in a browser with WebGPU.

Find the source and build instructions in the
[repository](https://github.com/tsnl/snail-scheme).
