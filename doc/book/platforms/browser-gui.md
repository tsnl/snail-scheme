# Browser (GUI)

**No implementation is available in this checkout.** This page reserves the
runtime for nodes that load browser artifacts and use browser UI.

The [node model](../nodes.md) explains a browser node communicating with a server.
The [browser startup contract](../runtime-contracts.md#a-server-runtime-spawning-a-browser-node)
explains how their runtimes cooperate during spawn. The available JavaScript
host is the command-oriented [Node.js runner](nodejs.md).
