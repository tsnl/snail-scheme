`recycle.svg` is the unchanged Font Awesome Free 6.7.2 solid recycle icon:
https://github.com/FortAwesome/Font-Awesome/blob/6.7.2/svgs/solid/recycle.svg

The icon is licensed under CC BY 4.0; its embedded attribution is preserved.
https://fontawesome.com/license/free

`style.css` embeds this exact SVG, including attribution, as a data URL so both
browser packages work offline and under a Pages path prefix. The source copy
here records the pinned upstream asset and does not require an extra HTTP fetch.
