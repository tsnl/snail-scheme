About this prototype

Game rules, client state, and shader expressions are Scheme libraries. Real WebGPU draws the field. A single local authority runs Scheme-generated Wasm, commits to SQLite, and streams accepted snapshots. Rebuilding swaps compatible code and shaders without resetting your match or selection. This tiny fixed map is an experiment, not the full game.
