Usage: snail-sfir run [OPTIONS] SOURCE.sfir [ARGUMENT ...]
       snail-sfir compile [OPTIONS] -o OUTPUT SOURCE.sfir

Compile explicit SFIR syntax. Chibi hosts the compiler; Binaryen is required.

  --target wasm|native       Select the target (default: wasm).
  -I DIR, --library DIR      Add an SFIR library search directory; may repeat.
  --generation-provider FILE
                            Select the JavaScript provider for generated libraries.
  -o FILE, --output FILE     Publish a completed compile artifact to FILE.
  -h, --help                Show this help without checking installed tools.

Arguments after SOURCE in run are passed literally to the program.
Native execution currently supports 64-bit x86-64 Linux.
