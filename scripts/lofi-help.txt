Usage: lofi run [OPTIONS] SOURCE.sld [ARGUMENT ...]
       lofi compile [OPTIONS] -o OUTPUT SOURCE.sld
       lofi wat [OPTIONS] SOURCE.sld
       lofi schema [OPTIONS] SOURCE.sld
       lofi serve [--port PORT] APP-DIRECTORY
       lofi watch [-I DIR] SOURCE.sld [ARGUMENT ...]
       lofi bootstrap

Compile a Lofi program to WasmGC, linked with the Rust runtime. The
compiler runs as Wasm, rebuilt from its own source when that changes;
Chibi starts the first bootstrap. Binaryen, Cargo and Node are required.

  --release        Optimize fully (the default is basic optimization).
  -I DIR           Add a library search directory; may repeat. lib/ is
                   always searched last.
  -o FILE          Where compile writes the program.
  -h, --help       Show this help.

run passes the arguments after SOURCE to the program. wat prints the
generated WebAssembly text without assembling it. schema prints the wire
schema of every type with a Serialize instance: each case's TypeId and
field types.

serve builds a (lofi app) application one library at a time, serves it at
http://127.0.0.1:PORT/ (8000 by default) and rebuilds the libraries its
edits reach; open pages relink the changed modules and keep their state.
watch builds and runs a program again whenever its sources change. Neither
builds a generate-library recipe yet.

bootstrap rebuilds the compiler until it reproduces itself.
LOFI_STAGE0=chibi compiles with the compiler's source running on Chibi
instead.
