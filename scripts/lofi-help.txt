Usage: lofi run [OPTIONS] SOURCE.sld [ARGUMENT ...]
       lofi compile [OPTIONS] -o OUTPUT SOURCE.sld

Compile .sld source using imported Lofi or Scheme forms.
Chibi hosts the compiler; Binaryen is required.

  -I DIR, --library DIR      Add a Lofi library search directory; may repeat.
  --generation-provider FILE
                            Select the JavaScript provider for generated libraries.
  -o FILE, --output FILE     Publish a completed compile artifact to FILE.
  -h, --help                Show this help without checking installed tools.

Arguments after SOURCE in run are passed literally to the program.
The compiler produces WasmGC. Run it with the Wasm host or package it for a browser.
