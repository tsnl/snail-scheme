Usage: lofi run [OPTIONS] SOURCE.sld [ARGUMENT ...]
       lofi compile [OPTIONS] -o OUTPUT SOURCE.sld
       lofi wat [OPTIONS] SOURCE.sld
       lofi repl [OPTIONS] [KERNEL.sld]
       lofi notebook [OPTIONS] [-o DIRECTORY] [KERNEL.sld]
       lofi bootstrap

Compile a Lofi program to WasmGC, linked with the Rust runtime. The
compiler runs as Wasm, rebuilt from its own source when that changes;
Chibi starts the first bootstrap. Binaryen, Cargo and Node are required.

  --release        Optimize fully (the default is basic optimization).
  -I DIR           Add a library search directory; may repeat. lib/ is
                   always searched last.
  -o FILE          Where compile writes the program, or notebook the
                   site (build/notebook by default).
  -h, --help       Show this help.

run passes the arguments after SOURCE to the program. wat prints the
generated WebAssembly text without assembling it. repl evaluates Scheme
at the terminal in a kernel, a program that uses define-kernel from
(lofi kernel); notebook builds a browser notebook around one. Both use
src/notebook/kernel.sld when no kernel is given. bootstrap rebuilds the
compiler until it reproduces itself. LOFI_STAGE0=chibi compiles with the
compiler's source running on Chibi instead.
